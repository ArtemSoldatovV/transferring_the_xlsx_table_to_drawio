# програма transferring_the_xlsx_table_to_drawio
## Требования для запуска
### - Java 21 язык программирования
### - среда программирования (программа делалась на IntelliJ IDEA 2024)
## как запустить
### 1) перенести pom.xml и папку src в одну папку, допустим в папку n
### 2) открыть папку n в среде программирования и запустить подгрузку библиотеки из pom.xml
### 3) запустить файл SimpleHttpServer.java находящийся в src\main\java\org\example\control_panel\web
